# 🖥️ Dashboard Application

A **modern, responsive React Dashboard** built with React and Tailwind CSS. This project includes dynamic routing, collapsible sidebar, call logs, appointments, and an adaptive header for mobile devices.


# 🛠 Technologies

 - React.js

 - React Router v6

 - Tailwind CSS

 - React Icons

 - JavaScript (ES6+)

 - HTML5 & CSS3



## 🌟 Features

- Fully responsive sidebar with collapsible menu
- Dynamic browser tab title based on current route
- Call logs with detailed information and conversation transcript
- Appointments management
- Mobile-friendly adaptive header
- Modern UI with gradient colors, badges, and shadows
- Easy to extend and maintain
